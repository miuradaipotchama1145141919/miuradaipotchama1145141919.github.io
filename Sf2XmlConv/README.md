# Sf2XmlConv

Sf2XmlConv converts a SoundFont2 (.sf2) file into a Domino module file by using a base Domino module as a template.

## Installation

1. Download or clone this project to your computer.
2. Open the project folder in a browser, or run a local web server from that folder.

## Usage

1. Select a base Domino module file, such as a GM2, GS, or XG template.
2. Select a SoundFont2 (.sf2) file.
3. Optionally enable the checkbox to reuse drum key names from the base file.
4. Click Convert.
5. The converted module file will download automatically.

The converter keeps the other settings from the base module and replaces the patch lists with the data from the SoundFont2.
